ChestInsight MATLAB-only demo images

Use these PNG files in the MATLAB app through "1. Choose X-ray".

Files 01 to 10 were selected from the local held-out NIH ChestX-ray14 pilot
test split because the named finding has a positive report-derived dataset label.
One X-ray can have multiple labels, so a filename does not mean it has only that
finding. File 11 has none of the ten selected target labels; it is not proof of
a clinically normal X-ray.

These images are for academic demonstration only. Do not use the model output
or image labels for diagnosis or treatment.
